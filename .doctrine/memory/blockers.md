# Blockers
> Ce qui bloque ou a bloqué — pour ne pas retomber dedans.

## Format
**[DATE] - Titre du blocage**
- **Symptôme** : Ce qui s'est passé
- **Cause** : Pourquoi ça a bloqué
- **Résolution** : Comment c'a été résolu (ou statut si ouvert)
- **Statut** : `ouvert` | `résolu` | `contourné`
